## <img src="./assets/rocket.svg" width="24" height="24" align="center" /> Projects

### Receipts-Express
Expense/receipt tooling with a fully self-hosted CI/CD pipeline. Architecture splits responsibilities between **GitHub Actions** and a self-managed **Jenkins** server (secrets scanning + SAST), with network access scoped through **Tailscale** and host-level firewall rules.

### Tickerboard
A local events aggregator for Seattle built with **FastAPI + SQLite + APScheduler**. Pulls event data from multiple sources and surfaces lead-time alerts so nothing sneaks up on you.

### Stringer PWA
A progressive web app for field videography work — aggregates live SPD/SFD 911 dispatch feeds with priority-alert modals, designed for fast triage from a phone in the field.

### Personal Assistant Stack ("JARVIS")
A self-hosted RAG pipeline built on **FastAPI + Claude + Voyage embeddings**, served over a **Tailscale** mesh network. Originally architected to drive a smart-glasses heads-up display, including a live fire-dispatch poller.
